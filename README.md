# 🚢 Titanic Survival Prediction - Production ML App

[![Watch the video](https://img.youtube.com/vi/NIVuqNWDNlo/0.jpg)](https://www.youtube.com/watch?v=NIVuqNWDNlo)

A full-stack production-ready Machine Learning application built using:

- FastAPI (Backend API)
- Streamlit (Frontend UI)
- Scikit-learn (Model)
- Docker & Docker Compose

## 🏗 Architecture

User → Streamlit → FastAPI → Trained Model
